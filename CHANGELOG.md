# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — 2026-10-17

### Изменено

- Название модуля — «[SH] ИИ база знаний», порядок в списке модулей — 1007.
  Название раздела в «Базе знаний» прежнее.

### Добавлено

- Статьи, которых больше нет в пакете, и все статьи пакета, которого больше нет
  в событии, уходят в корзину «Базы знаний» (`DeleteDocumentCommand` ядра,
  восстанавливаются из корзины); соответствие убирается. Правленные руками и
  архивные документы не трогаются — только строка в отчёте.
- Защита: событие без пакетов — ничего не удаляется; сбор с ошибками —
  пропавшие пакеты не удаляются; пакет с ошибками чтения — его статьи не удаляются.
- В отчёте импорта: «удалено в корзину», «нет в пакете, оставлены» и список оставленных.

## [1.0.0] — 2026-10-16

Первый выпуск: база знаний вынесена из shef.toolsai в отдельный модуль
поверх штатной «Базы знаний» Битрикс24 (`note`).

### Добавлено

- Раздел «ИИ: База знаний» в `note`: читают все, автор — модератор.
- Событие `shef.toolsaikb:OnKbSourcesCollect`: модули отдают пакеты статей `*.md`.
- Идемпотентный импорт с таблицей соответствий
  (в базе — `shef_toolsaikb_mapping`): ручные правки в `note` не затираются,
  документы в архиве и корзине не трогаются, удалённые создаются заново.
- Агент раз в сутки и кнопка «Обновить статьи» на странице настроек; первый
  импорт при установке.
- `Shef\ToolsAiKb\Public\Service\KbSearchService::find()` и ajax
  `shef:toolsaikb.search.find`: поиск с правами пользователя, по умолчанию
  только в своём разделе (`KB_searchall` — по всей «Базе знаний»), кеш 60 с;
  разбор вопроса перенесён из `Shef\ToolsAi\Kb\Rag` (shef.toolsai).
- Удаление модуля оставляет ID раздела и таблицу соответствий —
  переустановка не плодит копии.
