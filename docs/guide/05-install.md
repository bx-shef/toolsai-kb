# Права, зависимости, установка и удаление

## Зависимости

| что | версия | где проверяется |
|---|---|---|
| PHP | 8.2+ | установщик |
| `main` | 22.600.300+ | установщик |
| `note` («База знаний») | 26.250.0+ — с ним сверен публичный API | установщик (`NEED_MODULES_BY_VERSION`) |
| shef.options | 3.0.0+ | установщик и `.settings.php` (`requireModules`) |
| shef.problems | 2.0.0+ | установщик и `.settings.php` |

От shef.toolsai модуль не зависит. Связь — только событием.

## Права

- **Раздел** «ИИ: База знаний»: все сотрудники — чтение (`view`), служебный
  пользователь shef.options — модератор. Дальше права раздела меняют в самой
  «Базе знаний».
- **Поиск** — права текущего пользователя на документы `note`.
- **Кнопка «Обновить статьи»** — право записи на модуль (`W`).
- **Пункт «ИИ база знаний» в меню шестерёнки вида «ИИ»** shef.toolsai — право
  чтения на модуль (`R`), как у страницы настроек.

## Установка

1. Проверки: UTF-8, PHP, модули и версии.
2. Таблица `shef_toolsaikb_mapping`.
3. Подписки из `installEvents` (1.1.2): `shef.toolsai:OnViewSettingsMenuBuild` →
   `Internals\Integration\ToolsAi\EventHandler\OnViewSettingsMenuBuildEventHandler::handle()`
   — пункт «ИИ база знаний» (ссылка на настройки модуля) в меню шестерёнки вида
   «ИИ» shef.toolsai 1.53+. Нет shef.toolsai или он старше — событие никто не шлёт.
4. Агент `\Shef\ToolsAiKb\Agent\Refresh::run();` раз в сутки.
5. Первый импорт; итог — в форме установки.

**Обновление копированием файлов** (установщик не запускается, 1.1.2): подписки
ставит `Main\Maintenance`, когда версия модуля не совпала с опцией
`SYS_eventsversion`. Зовут его агент «Обновить статьи» и страница настроек: своей
подписки на каждый хит у модуля нет, а эти две точки есть с первой версии. Значит,
пункт в меню появится не позже чем через сутки — или сразу после открытия
настроек. Повтор безвреден: ядро не плодит дублей подписок.

## Удаление

- агент, блокировки и подписки снимаются;
- без «сохранить данные» удаляются настройки — **кроме ID раздела**;
- **раздел и документы в «Базе знаний» остаются** — это содержимое портала,
  их могли поправить люди. Вместе с ними всегда остаются ID раздела
  (`SYS_collectionid`) и таблица соответствий `shef_toolsaikb_mapping`:
  переустановка продолжит с тех же документов и не создаст копий.
  Убрать всё совсем — удалить раздел в «Базе знаний» и таблицу руками.

## Настройки

| код | что | по умолчанию |
|---|---|---|
| `KB_collectionname` | название раздела при создании | «ИИ: База знаний» |
| `KB_agent` | обновлять раз в сутки | Y |
| `KB_searchall` | искать по всей «Базе знаний», а не только в своём разделе | N |
| `SYS_collectionid` | ID раздела (пишет импорт) | — |
| `SYS_lastreport` | итог последнего импорта | — |
