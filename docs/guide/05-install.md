# Права, зависимости, установка и удаление

## Зависимости

| что | версия | где проверяется |
|---|---|---|
| PHP | 8.2+ | установщик |
| `main` | 22.600.300+ | установщик |
| `note` («База знаний») | 26.250.0+ — с ним сверен публичный API | установщик (`NEED_MODULES_BY_VERSION`) |
| shef.options | 3.0.0+ | установщик и `.settings.php` (`requireModules`) |
| shef.problems | 2.0.0+ | установщик и `.settings.php` |

От shef.toolsai модуль не зависит. Связь — только событием.

## Права

- **Раздел** «ИИ: База знаний»: все сотрудники — чтение (`view`), служебный
  пользователь shef.options — модератор. Дальше права раздела меняют в самой
  «Базе знаний».
- **Поиск** — права текущего пользователя на документы `note`.
- **Кнопка «Обновить статьи»** — право записи на модуль (`W`).

## Установка

1. Проверки: UTF-8, PHP, модули и версии.
2. Таблица `shef_toolsaikb_mapping`.
3. Агент `\Shef\ToolsAiKb\Agent\Refresh::run();` раз в сутки.
4. Первый импорт; итог — в форме установки.

## Удаление

- агент и блокировки снимаются;
- без «сохранить данные» — таблица соответствий и настройки удаляются;
- **раздел и документы в «Базе знаний» остаются** — это уже содержимое
  портала. Переустановка без сохранения данных создаст новый раздел и
  статьи рядом со старыми: удалите старый раздел руками, если не нужен.

## Настройки

| код | что | по умолчанию |
|---|---|---|
| `KB_collectionname` | название раздела при создании | «ИИ: База знаний» |
| `KB_agent` | обновлять раз в сутки | Y |
| `SYS_collectionid` | ID раздела (пишет импорт) | — |
| `SYS_lastreport` | итог последнего импорта | — |
