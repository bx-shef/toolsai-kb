# Что делает модуль и зачем

У модулей линейки shef.* есть справка: как настроить, что значит каждая
настройка, что делать при сбое. Раньше shef.toolsai показывал её своим сайтом
внутри портала. Теперь справка живёт в штатной «Базе знаний» Битрикс24
(модуль ядра `note`, адрес `/note/`): там её читают сотрудники, ищут обычным
поиском, правят и обсуждают.

Модуль shef.toolsaikb:

1. **создаёт раздел** «ИИ: База знаний» (название — в настройках);
2. **собирает пакеты статей** от модулей — событием `OnKbSourcesCollect`;
3. **импортирует** их в раздел: пакет — документ верхнего уровня, статьи —
   его дочерние документы;
4. **обновляет** статьи раз в сутки и по кнопке, не затирая ручные правки;
5. **ищет** статьи для других модулей с правами пользователя — например,
   для чата ИИ-помощника (shef.toolsaiassistant).

Статьи хранятся и правятся только в `note`. Модуль хранит лишь
соответствие «файл пакета -> документ» и хэш последнего записанного.
